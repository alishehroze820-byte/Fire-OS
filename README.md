# 🔥 Fire OS

A custom Android ROM based on LineageOS 18.1.

## Device
- Device: Oppo A37f
- Chipset: Qualcomm Snapdragon 410
- Android Version: 11
- Base ROM: LineageOS 18.1

## Features
- Pixel-inspired UI
- Custom Fire OS boot animation
- Custom wallpapers
- Pixel-style icons
- Custom launcher
- Performance optimizations

## Version
Fire OS 1.0

## Status
Development in progress.
